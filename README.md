# 🌌 PRAKHAR. | AI-Driven Creative Portfolio

A high-performance, minimalist portfolio built with **Next.js 16**, **Tailwind CSS**, and **Framer Motion**. This site features a "Glass Floor" aesthetic, responsive navigation, and smooth motion transitions designed to showcase the bridge between Computer Science and AI.



## 🚀 Live Demo
**Check out the live site here:** [prakhar-sharma.vercel.app](https://prakhar-sharma.vercel.app/)

---

## 🛠️ Tech Stack
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS (Modern Dark Mode)
* **Animations:** Framer Motion
* **Icons:** React Icons
* **Deployment:** Vercel

## ✨ Key Features
* **Responsive Navbar:** Adaptive background blur and scrolling logic with a primary "Resume" CTA.
* **Cyber-Poet Aesthetic:** A dark-themed, blueprint-inspired UI using monospaced typography and high-tracking text.
* **Project Showcase:** Interactive cards with hover effects and smooth entry animations.
* **Mobile Optimized:** Seamless experience across desktop, tablet, and mobile devices.
